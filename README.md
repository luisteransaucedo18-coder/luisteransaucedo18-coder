## Sobre mí

Soy estudiante de **Ingeniería de Sistemas e Informática en la Universidad Tecnológica del Perú**, en IX ciclo y perteneciente al tercio superior. Vivo en **Trujillo, Perú**.

Mi experiencia abarca desarrollo frontend y backend, pruebas funcionales, validación de APIs y coordinación de equipos. En mis repositorios encontrarás sistemas de gestión, recomendaciones basadas en reglas, experiencias web 360 y sitios institucionales. Me interesa entender el flujo completo de una aplicación: desde los requerimientos y los datos hasta la experiencia del usuario y la validación de cada entrega.

- **Desarrollo:** interfaces con React y TypeScript, servicios con Node.js y aplicaciones con Python y Flask.
- **Calidad:** pruebas funcionales, validación de APIs con Postman y documentación de incidencias reproducibles.
- **Colaboración:** organización de tareas, revisión de código y seguimiento de entregas con GitHub y ClickUp.
